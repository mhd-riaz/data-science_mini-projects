**Student:** Mohamed Riaz

**Course:** ML1 — Supervised Machine Learning (Regression)

Predicts the sale price (in Lakhs) of Bengaluru residential listings from `train.csv`, enriched with
the two supplied reference datasets (`avg_rent.csv`, `dist_from_city_centre.csv`). Evaluation metric
is **RMSE**.

## Headline result

| Metric | Value |
|---|---|
| **Held-out validation RMSE** (20% stratified holdout, n = 2,132, never cleaned) | **80.258 Lakhs** |
| Held-out MAE | 26.137 Lakhs |
| Held-out R² | 0.7491 |
| 5-fold cross-validated RMSE | 72.747 ± 6.875 Lakhs |
| Final model | 50 % RandomForest (raw target) + 50 % GradientBoosting (log1p target, Duan smearing) |
| Engineered features | 28 |
| RMSE gained from the two external datasets | 4.225 Lakhs |

## Setup

Run from the repository root (the folder containing `ML_regression_classification/`):

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r ML_regression_classification/output/requirements.txt
```

Python 3.12 was used. Any Python ≥ 3.10 that supports the pinned wheels will work.

## How to run

One command, no manual edits — it executes the notebook top to bottom, regenerates every figure and
rewrites the submission file:

```bash
jupyter nbconvert --to notebook --execute --inplace \
  --ExecutePreprocessor.timeout=3600 \
  ML_regression_classification/output/notebook/PES1PGE25DS037_hackathon.ipynb
```

Or open `notebook/PES1PGE25DS037_hackathon.ipynb` in Jupyter/VS Code and choose *Run All*.

The notebook locates `data/` by walking up from the current working directory, so it runs correctly
from the repository root, from `ML_regression_classification/`, or from `output/notebook/`. Runtime
is roughly 3–4 minutes on an Apple-silicon laptop.

## Verification built into the notebook

The last code cell of Section 8 asserts that the written submission has the same column names and
order, the same dtypes, and the same row count and `ID` sequence as `sample_submission.csv` /
`test.csv`, and that no prediction is missing or non-positive. A failed assertion aborts the run.

> **Specification note.** `docs/problem_statement.md` describes the submission columns as `ID` /
> `Price`, but the actual `sample_submission.csv` header is `ID,price` (lower-case `price`). The
> file is treated as authoritative and the column names are read from it at runtime.
